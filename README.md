# Analyst Greid Bot

Закрытый Telegram-бот для оценки грейда системного аналитика. Пользователь
проходит тест из 100 вопросов Junior, Middle и Senior, после чего получает число
правильных ответов, взвешенные баллы и ориентировочный грейд.

## Возможности

- доступ только для Telegram ID из конфигурации;
- постоянное меню «Пройти тестирование» / «Посмотреть результаты»;
- четыре варианта ответа на каждый вопрос;
- пауза с выбором: сохранить прогресс или удалить ответы;
- автоматическое продолжение сохранённого теста с нужного вопроса;
- хранение завершенных попыток и выбранных вариантов в SQLite;
- просмотр последнего результата пользователя;
- выгрузка полного персонального отчета в TXT.
- отдельный раздел администратора с результатами всех пользователей;
- просмотр оценки и выгрузка полной анкеты выбранного пользователя.

## Установка

Требуется Python 3.9+.

```bash
cd /Users/protonlol/projects/analyst-greid-bot
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
```

Заполните `.env`:

```dotenv
BOT_TOKEN=token-from-botfather
ALLOWED_USER_IDS=123456789,987654321
ADMIN_USER_IDS=123456789
DATABASE_PATH=data/results.sqlite3
```

`ALLOWED_USER_IDS` — Telegram ID пользователей через запятую. Чтобы добавить или
удалить пользователя, измените только эту строку и перезапустите приложение.
Если список пуст или содержит нечисловое значение, бот не запустится, что
защищает от случайного открытия доступа.

`ADMIN_USER_IDS` — ID администраторов через запятую. Администраторы автоматически
получают доступ к боту и видят дополнительный пункт меню с последними попытками
всех пользователей и выгрузкой полных анкет.

Запуск:

```bash
python -m app
```

Проверка:

```bash
python -m pytest -q
```

## Результат и грейд

За правильный Junior-ответ начисляется 1 балл, Middle — 2, Senior — 3.
Максимум — 185 баллов. Ориентировочный грейд определяется по доле баллов:

- менее 50% — Junior;
- от 50% до 74,99% — Middle;
- от 75% — Senior.

В SQLite сохраняются все завершенные попытки. В меню показывается последняя,
а полный отчет содержит каждый вопрос, выбранный и правильный варианты и
пояснение. Незавершенный тест не сохраняется.

Оценка является вспомогательным инструментом и должна использоваться вместе с
интервью и критериями конкретной компании.
